# Dialog Campaign Engine (对话式战役学习引擎)

> **“你看懂了，不代表你会了。你只有算错、选错、被坑过，知识才是你的。”**

Dialog Campaign Engine 是一个**开箱即用、具备静默自举能力**的 AI Agent Skill。

它不把视频压缩成一份泛泛的摘要，而是先做出一份带时间戳的完整讲义，再通过对话把你放进需要判断、计算或选择的真实场景里。

## 它能处理什么

| 视频类型 | 适合的例子 | 它的解决方式 |
| --- | --- | --- |
| 多集公开课与理论长课 | 博弈论、经济学、计算机网络、分布式系统 | 先确认当前学习哪一集；按该集原有时间线拆成知识关卡，避免把 24 集内容混成一锅。 |
| 财经、商业与认知分析 | 财富自由、公司战略、投资逻辑、商业案例 | 把观点改写成资金、目标、约束条件明确的决策局；你先选策略，再理解收益、风险和前提。 |
| 规则型与应试型课程 | 科目四、法规、安全规范、资格考试规则 | 把规则变成具体路况、边界条件或案例题；错了直接定位规则来源和原视频时间点。 |
| 有强因果链的技术原理课 | TCP、Raft、缓存、数据库事务、AI 原理 | 用故障、请求流或系统约束做情境；你判断下一步，AI 再解释机制如何运转。 |
| 可读文本资料 | PDF 讲义、研报、案例材料 | 先构建完整结构化讲义，再按概念、案例或规则进入对话式训练。 |

它**不适合**只靠“听懂原理”无法完成的内容，例如纯软件安装、跟着鼠标点按钮的操作教程、依赖画面细节的剪辑教学、纯娱乐 Vlog。对这些内容，应该使用步骤清单、截图标注或跟做式教程，而不是强行设计成决策关卡。

## 它会怎么处理一条视频

1. **解析与分集**：读取字幕、文本和必要的画面信息。遇到播放列表，先问你要从哪一集开始。
2. **建立完整底座**：为每个核心概念标注原视频时间戳，产出完整的 Markdown 讲义；本机工具支持时再生成 PDF 或 HTML，供你之后对照视频复看。
3. **对话闯关**：不先讲定义，而是给你一个有角色、数字和限制条件的场景。你必须先做判断。
4. **即时纠偏**：答对后才补上专业名词；答错时指出遗漏的前提，并给出视频和讲义的具体时间点。
5. **迁移验证**：最后给一个换了行业和条件的综合情境，确认你掌握的是规则，而不只是记住原视频的例子。

## 你最后会拿到什么

| 产物 | 用途 |
| --- | --- |
| 带时间戳的完整讲义 | 后续想看原视频时，能直接跳到某个概念所在的位置。 |
| 连续的场景问答 | 用决策、计算和解释取代被动观看。 |
| 错误记录与回看点 | 知道自己错在什么前提，而不是只看到正确答案。 |
| 最终变式题与抽象框架 | 验证知识能否迁移到新问题。 |

## 使用方式

1. 把整个 `dialog-campaign-engine` 文件夹安装到 Agent 的技能目录，不要只复制 `SKILL.md`；`scripts/` 里的首次环境补齐工具也要一起保留。
2. 在聊天框发视频链接或 PDF，并说清学习目标。比如：

   > 这是耶鲁博弈论第 2 集的链接。我不想先看视频，带我用对话掌握这一集；同时生成一份带时间戳的完整讲义，之后我会对照视频复看。

   > 这是一个讲资产配置的视频。不要泛泛总结，给我真实资金和风险约束，让我自己做选择。

## 首次环境补齐

这个 skill 的教学逻辑、时间戳讲义和对话流程都已经包含在安装包里；下载者不需要再去找 `watch`、`NovaForge` 或其它同名 skill。

第一次遇到视频时，AI 会自动检查本机是否已有 `yt-dlp`、FFmpeg 和 Whisper 转写能力：

- 已有：直接解析并开始学习。
- 缺少：AI 只会问一次“现在自动补齐吗？”。用户确认后，AI 运行本包附带的 `scripts/setup.ps1` 完成安装；之后不需要重复配置。
- 拒绝或安装失败：AI 会明确说明缺少的是字幕、音频访问、转写工具还是视觉信息，不会假装已完整理解视频。

安装脚本会联网下载开源依赖，因此不能在下载 skill 时无声执行，也不会在未获确认时修改用户电脑。这是为了避免一个 GitHub skill 在用户不知情的情况下安装程序或下载模型。

## 必须诚实的边界

- 无法取得字幕和音频时，不能保证完整覆盖视频的口头内容。
- 教学若主要依赖屏幕画面、图表、公式推导或操作细节，还需要可用的画面提取与视觉理解能力；仅凭音频转写不够。
- 纯软件安装、鼠标操作教程和娱乐 Vlog 不适合强行做成决策闯关。
